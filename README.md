# PizzaBin Windows Releases

Public **download assets only** for the PizzaBin Windows updater (sandbox PoC and later signed installers).

- App source stays in the private [PizzaBin-Windows](https://github.com/scut093/PizzaBin-Windows) repo.
- Release zips/exes are published here so update `download_url`s work without a GitHub token.
- Metadata (version + URL) lives in Supabase table `update_metadata_windows_sandbox` (Windows-only; not the Android update tables).
